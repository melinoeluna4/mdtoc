Documentation · Go CLI

mdtoc

Un README largo sin índice es un muro de texto. mdtoc lee los headings, ignora los bloques de código y genera una tabla de contenidos anidada en una sola línea de terminal.

Qué es

Una CLI pequeña que convierte un documento Markdown en un índice navegable. Acepta un archivo o stdin, respeta la jerarquía de # a ###### y genera anchors al estilo GitHub.

Sin dependencias externas. El binario se instala con go install y funciona igual en local que en un runner de CI.

Instalación

go install github.com/melinoeluna4/mdtoc@latest

Uso

Desde un archivo o desde una tubería. El resultado se pega en el documento.

$ mdtoc README.md

Cambia la profundidad o el marcador: 

cat README.md | mdtoc -max-depth 2
mdtoc -bullet "*" docs/guide.md

Flags

FlagDefaultQué hace
-max-depth3Profundidad máxima de headings (1–6).
-bullet-Marcador de la lista.

Decisiones

  • Los bloques de código con ``` o ~~~ se ignoran: un # dentro de un ejemplo no es un heading.
  • Los slugs añaden -0, -1 cuando dos headings se repiten.
  • El parser es deliberadamente pequeño: headings ATX, no un motor Markdown completo.
